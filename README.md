# 帧外 FRAMEOUT

以黑白、荧光绿、窄体海报字和影像拼贴为视觉语言的 AI 创作画布。支持接入自己的 API Key 生成图片、提交视频任务，并把结果编排成镜头序列。

## 本地运行

无需安装依赖。进入本目录后运行：

```bash
node scripts/dev-server.mjs
```

打开 http://127.0.0.1:4188 。`#studio` 可直接进入创作画布。开发服务同时提供前端页面与 `/api/ai` 转发，单独启动静态服务器无法使用官方 API 转发。

需要更换端口时运行 `PORT=4189 node scripts/dev-server.mjs`。

## API 接入

1. 在画布中打开「API 设置」，选择供应商并填入自己的 API Key。
2. 确认图片模型、图片尺寸，以及需要使用的视频模型和视频参数；火山方舟可填写已开通的模型名或 `ep-…` 接入点 ID。
3. 点击「测试连接」验证地址与鉴权，再保存配置。连接成功不代表所选模型已开通，生成权限与费用以供应商实际响应为准。
4. 在生成框选择「真实图片」或「真实视频」，输入提示词并生成。选中图片后点击「生成视频」，会把该图片作为首帧提交。

| 供应商 | 能力 | 请求方式 |
| --- | --- | --- |
| OpenAI 官方 | Images API 图片生成 | 站点转发至固定官方地址 |
| 火山方舟 | Seedream 图片、Seedance 视频提交与状态查询 | 站点转发至固定北京区官方地址 |
| 自定义 OpenAI 兼容 | Images 与 `/videos` 协议，取决于中转服务 | 浏览器直接请求所填 Base URL；中转必须允许本站跨域 |

OpenAI 官方 Sora / Videos API 已于 2026 年 9 月 24 日下线，因此官方配置只提供生图；生视频请选择火山方舟或仍提供对应协议的兼容服务。[OpenAI 官方接口说明](https://developers.openai.com/api/reference/resources/videos/methods/create)

Key 按供应商隔离，默认只保留在当前页面内存中，刷新后需重新填写。配置保存只记录供应商、模型、尺寸等参数，不将 Key 写入浏览器持久存储、项目 JSON 或导出文件。「清除本页所有密钥」也会停止当前页面正在等待的请求。

视频任务取得任务号后可「停止等待」，稍后选中任务卡片继续查询同一任务；此操作不会向供应商取消任务，也不会自动重新提交。若提交中断且没有取得任务号，请先到供应商控制台确认状态，避免重复提交。

## 已实现

- 响应式首页、三个灵感示例入口、动态取景弹窗。
- 分字与遮罩编排的开场、阻尼鼠标视差、可逆的滚动场景（素材散落 → 主镜头 → 镜头序列）、案例错峰揭露与首页/画布转场。
- 新素材入场、镜头序列重排动画；直接手势即时跟手，缩放按钮与适应素材使用约 180ms 的短过渡。
- 无限画布二维平移、光标锚定缩放、触屏双指手势、素材拖拽与选择；相机更新按帧合并。
- 缩放比例输入、常用比例预设与适应全部素材；选中工具栏随素材移动，保持屏幕尺寸并避让边缘。
- 上传本地图片或视频、删除、撤销与重做。
- OpenAI / 火山方舟前端协议适配、自定义兼容接口、连接测试与真实生成；失败明确显示原因，不回退成演示结果。
- 视频任务状态、停止本页等待与按已有任务号继续查询；图片首帧转视频。
- 明确区分真实 API 与演示素材；演示模式保留内置图片与动态取景。
- 镜头加入成片组、拖拽排序、前后移动、设置每镜时长、连续播放预览。
- 浏览器本地保存与恢复、导出项目 JSON；返回画布或刷新后保留相机位置与比例。
- 键盘快捷键、可见焦点、减少动态效果偏好适配。

## 画布操作

- 普通滚轮或触控板滚动：二维平移画布；按住 Ctrl / Cmd 滚动：以光标为锚点缩放。
- 触屏双指：移动中点平移，捏合缩放；拖动素材可调整位置。
- 空白处拖动，或按住空格拖动：平移画布。V 切换选择工具，H 切换抓手工具。
- 点击右下角比例可输入 15%～400%，或选择 50%、100%、200%；适应按钮将全部素材移回视野。
- 选中素材后使用浮动工具栏生成视频、继续查询、下载、加入成片或删除；缩小画布不会缩小按钮。

## 使用范围

生成请求按所选供应商账户计费。演示模式使用内置素材，动态取景使用静态图片展示镜头运动；真实模式使用供应商返回的图片或视频。

返回为图片编码或视频文件的生成素材保存到当前浏览器的 IndexedDB，项目 JSON 仅记录素材引用。供应商返回 HTTPS 链接时，画布保留该链接；链接可能过期，请及时下载。浏览器存储不可用时只保留当前会话结果，并提示下载。本地手动上传的文件仍仅在当前页面会话可用，刷新后需重新选择。

创作状态与生成素材不会上传到站点存储；调用 API 时，提示词和选作首帧的图片会发送到所选供应商。导出项目 JSON 不包含本地素材文件，移到其他浏览器后需重新关联素材。

当前支持镜头排序、时长调整和浏览器连续预览，尚未接入将整条序列编码合成为 MP4 的导出功能。供应商生成的单段视频可以下载。

## 构建与发布

```bash
node scripts/build-worker.mjs
node scripts/validate-worker.mjs
```

前端源码位于 `web/`。构建将页面、脚本、样例素材和 API 转发层嵌入单个 ESM Worker，生成 `dist/server/index.js` 与 `dist/.openai/hosting.json`。`dist/` 是生成目录，不应手改。发布继续复用现有 Sites 项目与公开访问配置。

## 文件

- `web/index.html`、`app.css`、`app.js`：原创首页和页面切换。
- `web/studio.js`、`studio.css`：画布、真实生成与演示、镜头序列和预览。
- `web/ai-client.js`：OpenAI / 火山方舟协议适配、连接测试和视频任务查询。
- `web/ai-settings.js`、`ai-settings.css`：供应商参数与仅内存保留的 Key 设置。
- `web/media-store.js`：生成素材的浏览器 IndexedDB 存储。
- `web/canvas-camera.js`：相机状态、缩放锚点、逐帧提交与短过渡控制。
- `web/motion.js`、`motion.css`：原生动效编排、减少动态效果偏好与离屏暂停。
- `worker/api.mjs`：只向指定官方主机与路径转发请求，不保存 Key。
- `worker/index.js`：Worker 路由与静态资源入口模板。
- `scripts/dev-server.mjs`、`build-worker.mjs`、`validate-worker.mjs`：本地预览、构建与产物验证。
- `web/icons.js`：代码绘制的矢量图标。
- `web/assets/`：原创森林剧照、摄影图、字体及来源和授权说明。

首页参考了 JIEJOE 的审美语言，页面代码、品牌标志和森林图均为此次制作，没有使用其恢复源码、授权字体或个人作品素材。

## 验证

本轮相机、API 兼容层、转发边界与密钥偏好单元测试共 49 项通过。桌面 1440×900 / 手机 390×844 的 API 模拟集成验收共 22 项通过，覆盖配置、图片缓存与刷新恢复、导出无密钥、错误脱敏、视频停止与续查、生成期间撤销保护，以及 5 秒任务的镜头与预览时长。全部使用模拟响应，尚未使用真实 Key 验证实际出图或出片。

本轮重新运行画布交互回归，桌面 1440×900 / 手机 390×844 共 42 项浏览器合成事件验收通过，覆盖滚动平移、光标锚点、连续缩放、拖卡坐标、取消与捕获丢失、双指转单指、工具栏避让、撤销、删除、成片预览和存档。上一版另在 Edge 实测 50% 下横纵滚动保持比例，并检查 390px 选中工具栏布局。尚未测量大规模素材画布帧率，也未完成真实多指捏合手感验证。

历史首页动效检查包括桌面滚动阶段 01→02→03→02→01 的可逆构图、鼠标拖拽、镜头重排、390×844 手机布局、首页/画布转场，以及减少动态模式下无残留遮罩。
