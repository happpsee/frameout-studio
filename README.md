# 帧外 FRAMEOUT

以黑白、荧光绿、窄体海报字和影像拼贴为视觉语言的 AI 视频创作网站交互原型。

## 本地运行

无需安装依赖。进入本目录后运行：

```bash
python3 -m http.server 4179 --directory dist --bind 127.0.0.1
```

打开 http://127.0.0.1:4179 。`#studio` 可直接进入创作画布。

## 已实现

- 响应式首页、三个灵感示例入口、动态取景弹窗。
- 分字与遮罩编排的开场、阻尼鼠标视差、可逆的滚动场景（素材散落 → 主镜头 → 镜头序列）、案例错峰揭露与首页/画布转场。
- 新素材入场、镜头序列重排动画；直接手势即时跟手，缩放按钮与适应素材使用约 180ms 的短过渡。
- 无限画布二维平移、光标锚定缩放、触屏双指手势、素材拖拽与选择；相机更新按帧合并。
- 缩放比例输入、常用比例预设与适应全部素材；选中工具栏随素材移动，保持屏幕尺寸并避让边缘。
- 上传本地图片或视频、删除、撤销与重做。
- 明确标注为演示的素材生成与动态取景。
- 镜头加入成片组、拖拽排序、前后移动、设置每镜时长、连续播放预览。
- 浏览器本地保存与恢复、导出项目 JSON；返回画布或刷新后保留相机位置与比例。
- 键盘快捷键、可见焦点、减少动态效果偏好适配。

## 画布操作

- 普通滚轮或触控板滚动：二维平移画布；按住 Ctrl / Cmd 滚动：以光标为锚点缩放。
- 触屏双指：移动中点平移，捏合缩放；拖动素材可调整位置。
- 空白处拖动，或按住空格拖动：平移画布。V 切换选择工具，H 切换抓手工具。
- 点击右下角比例可输入 15%～400%，或选择 50%、100%、200%；适应按钮将全部素材移回视野。
- 选中素材后使用浮动工具栏生成演示视频、加入成片或删除；缩小画布不会缩小按钮。

## 使用范围

当前没有接入真实 AI 生成服务和 MP4 编码导出。演示生成使用内置素材，动态预览以图片镜头运动展示节奏。本地上传的文件使用会话对象地址，刷新后需要重新选择；其余创作状态保存在当前浏览器，不会上云。

## 文件

- `dist/index.html`、`app.css`、`app.js`：原创首页和页面切换。
- `dist/studio.js`、`studio.css`：画布、生成演示、镜头序列和预览。
- `dist/canvas-camera.js`：相机状态、缩放锚点、逐帧提交与短过渡控制。
- `dist/motion.js`、`motion.css`：原生 Web Animations / requestAnimationFrame 动效编排，尊重减少动态效果偏好，装饰动画离屏暂停。
- `dist/icons.js`：代码绘制的矢量图标。
- `dist/assets/forest-astronaut.png`：使用内置 imagegen 新生成的森林探索者剧照。
- `dist/assets/IMAGE-PROMPT.md`：原创图生成提示词和说明。
- `dist/assets/SOURCES.md`：摄影图和 Anton 字体来源。
- `dist/assets/ANTON-LICENSE.txt`：Anton 的 SIL OFL 授权。

首页参考了 JIEJOE 的审美语言，页面代码、品牌标志和森林图均为此次制作，没有使用其恢复源码、授权字体或个人作品素材。

## 验证

画布交互更新通过 11 项相机单元测试，以及桌面 1440×900 / 手机 390×844 共 42 项浏览器合成事件验收，覆盖滚动平移、光标锚点、连续缩放、拖卡坐标、取消与捕获丢失、双指转单指、工具栏避让、撤销、删除、成片预览和存档。另在 Edge 实测 50% 下横纵滚动保持比例，并检查 390px 选中工具栏布局。尚未测量大规模素材画布帧率，也未完成真实多指捏合手感验证。

已检查 JavaScript 语法，并在浏览器验证首页/画布切换、素材生成演示、撤销重做、镜头加入与播放预览；桌面与 390px 手机宽度均已截图检查。动效更新另验证了桌面滚动阶段 01→02→03→02→01 的可逆构图、鼠标拖拽、镜头重排、390×844 手机布局、首页/画布转场，以及减少动态模式没有长空白或残留遮罩。页面控制台无异常。真实 AI 与视频编码属于后续接入范围。

相机模块测试无需安装依赖，在仓库根目录运行：

```bash
node --test tests/canvas-camera.test.cjs
```

浏览器集成检查页需要从仓库根目录提供静态文件：

```bash

```

打开 http://127.0.0.1:4189/tests/browser.html 查看检查结果。集成页使用合成手势，不能替代真实设备上的捏合与跟手体验测试。
