# 在帧外里做短片

帧外的工具都作用于**当前打开的项目**。先 `get_project`，后面的工具都用它返回的 id。帧外没开会返回 `APP_NOT_RUNNING`，请用户打开帧外桌面版和项目，不要改用点击界面的方式。

## 工具

| 工具 | 用途 |
| --- | --- |
| `list_projects` / `open_project` | 列出项目、打开项目（其他工具都作用于打开的项目） |
| `get_project` | 卡片、连线、文本、一致性、成片、音频轨、花费，以及 `version` |
| `view_card` | 看一张卡片：图片原样缩小；视频给 8 帧拼图并写明每帧的秒数 |
| `import_media` | 把本机文件导入画布，不经过文件选择框 |
| `extract_frame` | 从视频某一秒取一帧，变成新的图片卡片 |
| `generate_image` | Seedream 生图，`references` 按顺序是提示词里的 图1、图2… |
| `generate_video` | Seedance 生视频：首帧，或全模态参考（参考图 @图像N + 从视频截的参考声音 @音频N） |
| `wait_card` | 等生成结束 |
| `edit_project` | 整批改：连线、文本、一致性、成片顺序（`set_film`）、音频轨；带 `version`，冲突就重读 |

会花钱的工具先 `dryRun: true` 报价。

## 做法（踩过的坑）

1. **先定人物，再拍**：每个角色先出三视图，用用户给的照片做参考，抓准最有辨识度的特征（眼睛、耳朵、脸型、花色）。之后所有镜头都拿三视图做参考。
2. **场景只用一个，机位固定**：短片尽量放在同一个场景里，先出场景图把谁站在哪定下来。
3. **每个分镜先出关键帧图片**，确认人物和位置都对了，再做成视频。
4. **视频一段接一段**：用全模态参考，`images` 第一张放上一段的最后一帧（`extract_frame` 的 `seconds` 设成视频长度），提示词写「以 @图像1 作为首帧」，后面跟角色三视图锁住长相。镜头之间才不会跳，人物也不会走样。
5. **每段生成后都用 `view_card` 检查**，对照提示词逐条看：人物像不像、动作有没有做出来、和上一段接不接得上。有问题先告诉用户，不要直接重拍。
6. **故事要有趣**：钩子（第一秒抓人）→ 反转 → 升级 → 爆点。同一句台词只出现一次，爆点只放一次、放在最后。
7. **花钱前先报价**：生成都按次计费，先告诉用户大概多少钱，得到同意再生成。生成一旦提交就会扣费，不能取消。
