# 在帧外里做短片

所有工具都通过帧外桌面版自己的接口操作，不要改用点击界面的方式。帧外没开会返回 `APP_NOT_RUNNING`，请用户打开帧外桌面版。

## 工具

| 工具 | 用途 |
| --- | --- |
| `list_projects` / `open_project` | 列出项目、打开项目；其他工具都作用于打开的项目 |
| `get_project` | 卡片、连线、文本、一致性、成片、音频轨、花费，以及 `version` |
| `view_card` | 看一张卡片：图片原样缩小；视频给帧拼图并写明每帧的秒数。`frames` 最多 24，`from`/`to` 盯住某一段 |
| `check_video` | 量出画面僵住的时间段、声音的响度/削波/高频占比，并给一张频谱图 |
| `import_media` | 把本机图片或视频导入画布，不经过文件选择框 |
| `extract_frame` | 从视频某一秒取一帧，变成新的图片卡片 |
| `generate_image` | Seedream 生图；`references` 按顺序是提示词里的 图1、图2… |
| `generate_video` | Seedance 生视频：首帧，或全模态参考（参考图 @图像N、从视频截的参考声音 @音频N） |
| `wait_card` | 等生成结束（ready / failed） |
| `edit_project` | 整批改：连线、卡片、文本、一致性、成片顺序（`set_film`）、音频轨（`add_sound` 等）；带 `version` |
| `export_film` | 导出 MP4 到本机（默认桌面） |

## 流程

1. **读项目**：`list_projects` → `open_project` → `get_project`。用户给的照片、视频用 `import_media` 放进画布。
2. **写故事，先给用户看**：钩子（第一秒抓人）→ 升级 → 反转 → 爆点。同一句台词只出现一次；爆点只放一次，放在最后。按分镜写清「几秒到几秒、谁做什么、说什么」。
3. **人物三视图**：每个角色一张，用用户的照片做参考，提示词里写出最有辨识度的特征（眼睛、耳朵、脸型、花色、配饰）。生成后 `view_card` 和照片对比，不像就说出哪里不像。
4. **场景和分镜 1 的关键帧**：一个场景、固定机位；关键帧同时参考场景图和三视图，把谁在哪定下来。构图要让角色足够大，别只拍远景。
5. **视频一段接一段**：每段用全模态参考，`images` 依次放「上一段最后一帧（分镜 1 用关键帧）、角色三视图…」，提示词写「以 @图像1 作为首帧」和「X 长相严格参考 @图像2」。上一段最后一帧用 `extract_frame`，`seconds` 设成视频长度。需要某种真实声音（比如猫哈气），从用户给的视频里截 2 秒以上作为 `sounds`。本地视频不能直接作为参考视频。
6. **每段都检查，检查完才能汇报**（见下面「检查清单」）。有问题先告诉用户、商量好再重拍，不要擅自重拍，也不要把有问题的片子说成做好了。
7. **编排成片**：`edit_project` 的 `set_film` 按顺序放镜头；需要换声音用 `add_sound`（`replace` 替换原声，`mix` 叠加）。改之前先 `get_project` 拿最新 `version`，碰到 `VERSION_CONFLICT` 就重读再改。
8. **导出**：`export_film`，竖屏短视频用 `9:16`。导出后告诉用户文件在哪、声音情况。

## 检查清单（每段视频生成后都要做）

只看 8 张小缩略图不算检查：看不出画面僵住，看不清脸，也完全不知道声音怎样。

1. `wait_card` 后先 `check_video`：
   - `still` 里有时间段 → 那几秒画面几乎不动，对照提示词看是哪个动作没演。
   - 看频谱图：声音出现的时刻和画面动作对不对得上（比如哈气是一片均匀噪声，应该正好在张嘴那一秒）；有没有某一段高频突然没了（发闷）；`clippedSamples` 是否大于 0。
2. `view_card` 用 `frames: 18` 以上看全段，逐条对照提示词里每个时间段：动作有没有发生、持续多久、顺序对不对。
3. 对关键时刻用 `from`/`to` 放大看：脸和身体有没有变形，角色特征有没有走样（对照三视图：眼睛颜色、耳朵、花色、配饰），手和道具是否正常。
4. 和上一段的接缝：上一段最后 0.5 秒和这一段最初 0.5 秒各看几帧。
5. 台词内容看不出来：明确告诉用户哪几句需要他听。
6. 汇报时先说问题，再说做成了什么。

写提示词时避免这些已知的坑：一段 5–6 秒只安排两三个动作；写明角色全程有自然的小动作，避免定格；猫哈气这类爆发动作只持续 1 秒左右；不要堆砌夸张的外形描述（如「头变得又宽又大、耳朵消失」），模型会画变形；参考音频先确认只含想要的声音，拿不准就不用，事后用音频轨替换。

## 花钱

- 生成按次计费，提交后不能取消。先用 `dryRun: true` 报价，告诉用户金额、得到同意再生成。
- 参考价（方舟，720p）：一张图约 ¥0.6；视频每秒约 ¥1.5，6 秒约 ¥9。
- 用户只同意了某一步，就只做那一步。
